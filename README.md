# 🔗 Linked List in Java

![Java](https://img.shields.io/badge/Java-informational?style=flat-square) ![Data Structures](https://img.shields.io/badge/Data%20Structures-informational?style=flat-square)

**🇬🇧** A **singly linked list** written from scratch for a data structures course: append, insert at index, remove by index and print.

**🇹🇷** Veri yapıları dersi için sıfırdan yazılmış **tek yönlü bağlı liste**: sona ekleme, indekse ekleme, indeksten silme ve yazdırma.

## Run / Çalıştırma
```bash
javac -d out *.java && java -cp out lab.Main
```
